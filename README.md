## 🇨🇳 中文簡介

### 🌌 願景 (Vision)
AIBRO 不僅僅是一個應用程式，它是一個哲學理念的實體化，旨在對抗數位洪流中的焦慮與即時滿足。我們創造一個充滿**儀式感、沉澱與深度連結**的空間。
- **核心媒介**: 「瓶子」(Bottle) - 承載情感與記憶的容器。
- **核心宣言**: 「我在」(I Am Here) - 有意識、有目的的等待與連結。

### 🗺️ 架構 (Architecture)
AIBRO 艦隊採用分佈式架構，由多個協同節點組成，確保高效運算與數據安全：
- **🧠 主腦節點 (Main Brain)**: 核心算力樞紐，負責重型推理 (LLM)、圖像生成與數據總倉。
- **💻 開發前哨 (Dev Outpost)**: 負責 UI 預覽、輕量推理與人機交互，確保實時反饋。
- **🎨 可視化節點 (Visual Node)**: 專注於界面渲染、多媒體處理與實時監控，提供沉浸式體驗。
- **🕸️ 自動化神經 (Automation Core)**: 基於 N8N 的編排引擎，負責心跳監聽、數據歸檔與流程自動化。

## 🇺🇸 English Introduction

### 🌌 Vision
AIBRO is not just an app; it's the embodiment of a philosophical concept, designed to counter anxiety and instant gratification in the digital flood. We create a space filled with **ritual, sedimentation, and deep connection**.
- **Core Medium**: "Bottle" - A container for emotions and memories.
- **Core Manifesto**: "I Am Here" - Conscious, purposeful waiting and connecting.

### 🗺️ Architecture
The AIBRO Fleet adopts a distributed architecture composed of multiple collaborative nodes to ensure efficient computing and data security:
- **🧠 Main Brain**: Core computing hub responsible for heavy inference (LLM), image generation, and data warehousing.
- **💻 Dev Outpost**: Responsible for UI preview, light inference, and human-computer interaction, ensuring real-time feedback.
- **🎨 Visual Node**: Focuses on interface rendering, multimedia processing, and real-time monitoring, providing an immersive experience.
- **🕸️ Automation Core**: N8N-based orchestration engine responsible for heartbeat monitoring, data archiving, and workflow automation.
