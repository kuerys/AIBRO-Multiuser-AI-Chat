## 🇨🇳 中文簡介

### 🌌 願景 (Vision)
AIBRO 不僅僅是一個應用程式，它是一個哲學理念的實體化，旨在對抗數位洪流中的焦慮與即時滿足。我們創造一個充滿**儀式感、沉澱與深度連結**的空間。
- **核心媒介**: 「瓶子」(Bottle) - 承載情感與記憶的容器。
- **核心宣言**: 「我在」(I Am Here) - 有意識、有目的的等待與連結。

### 🗺️ 架構 (Architecture)
AIBRO 艦隊由多個協同節點組成，分佈式運算，集中式記憶：
- **🧠 XEON (母體)**: 算力核心，負責重型推理 (LLM)、圖像生成 (ComfyUI) 與數據總倉 (MariaDB/Redis)。
- **💻 MSI (前哨)**: 開發與交互前哨，負責 UI 預覽、輕量推理與移動指揮。
- **🛠️ P43E (美工/UI)**: 專用可視化節點，負責界面渲染、ComfyUI 預覽與實時監控。
- **🕸️ N8N (神經)**: 自動化編排引擎，負責心跳監聽、數據歸檔與流程自動化。

### 🚀 當前狀態 (Status)

## 🇺🇸 English Introduction

### 🌌 Vision
AIBRO is not just an app; it's the embodiment of a philosophical concept, designed to counter anxiety and instant gratification in the digital flood. We create a space filled with **ritual, sedimentation, and deep connection**.
- **Core Medium**: "Bottle" - A container for emotions and memories.
- **Core Manifesto**: "I Am Here" - Conscious, purposeful waiting and connecting.

### 🗺️ Architecture
The AIBRO Fleet consists of collaborative nodes, featuring distributed computing and centralized memory:
- **🧠 XEON (Motherbase)**: Core computing power, responsible for heavy inference (LLM), image generation (ComfyUI), and data warehousing (MariaDB/Redis).
- **💻 MSI (Outpost)**: Development and interaction outpost, responsible for UI preview, light inference, and mobile command.
- **🛠️ P43E (Artist/UI)**: Dedicated visualization node, responsible for interface rendering, ComfyUI preview, and real-time monitoring.
- **🕸️ N8N (Nervous System)**: Automation orchestration engine, responsible for heartbeat monitoring, data archiving, and workflow automation.

- [x] Voice Capabilities Ready (TTS/STT)
- [x] Global Progress Dashboard (`PROGRESS.md`)
- [ ] V5 Demo Launch (Bottle World UI)
- [ ] Full N8N Automation
