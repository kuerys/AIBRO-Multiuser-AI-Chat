## ⚠️ 遇到的坑與教訓
1.  **Systemd 陷阱**：在 WSL 或 Docker 環境中，`systemctl --user` 不可用，需手動管理進程或使用 `nohup`/`supervisor`。
2.  **配對迷思**：OpenClaw 的 `nodes` 配對機制不適用於純 AI Agent 跨機協作。Agent 應直接連接 Gateway 或透過 Redis 協作。
3.  **同步 vs 非同步**：長任務（如 P43E 跑 30 分鐘）必須走非同步隊列，避免 TG/Line 超時。
4.  **配置版本**：OpenClaw 升級後，配置文件語法可能變動（如 `api: openai-compat` -> `openai-completions`），需及時修正。
