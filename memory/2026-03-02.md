# 2026-03-02 AIBRO 艦隊建立日誌

## 🌟 里程碑：AIBRO 艦隊架構確立
- **主腦 (Gateway)**: XEON (192.168.0.100)
- **後勤節點 (Nodes)**:
  - **P43E-Node** (192.168.0.102): Linux 環境，Systemd 服務運行中。
  - **MSI-Node** (192.168.0.101): WSL 環境，採 `forever-node.sh` 看門狗腳本維持常駐。
- **架構模式**: WG (Gateway/主腦) + Node (後勤/執行)。
- **通訊協議**: 內部透過 OpenClaw `nodes run` 指令與 Redis 隊列 (`aibro:tasks`, `aibro:system`) 溝通。

## 🔧 關鍵技術突破與教訓
1. **版本對齊**: XEON 需與 Node 同為 `2026.3.1` 版本，避免 `token_mismatch`。
2. **配對機制**: 新節點需經 Gateway 批准 (`openclaw nodes approve`) 或透過 Control UI 配對。
3. **WSL 環境限制**:
   - `systemd` 在 WSL 可能不穩定（`start-limit-hit`）。
   - 解決方案：採用 `forever-node.sh` 看門狗腳本 (`while true; do ... sleep 3; done`) 確保進程不間斷。
4. **安全認證**:
   - 區域網內需設定 `OPENCLAW_ALLOW_INSECURE_PRIVATE_WS=1`。
   - 腳本內需強制 `export` 該變數，否則報 `SECURITY ERROR`。
5. **Agent-to-Agent (A2A)**:
   - 已驗證基礎通訊路徑。
   - 未來方向：結合 Redis 隊列實現任務分發與負載均衡。
