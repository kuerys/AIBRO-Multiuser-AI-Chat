```json
{
  "channels": {
    "telegram": {
      "allowFrom": ["*"],

      "groupPolicy": "open",
      "accounts": {
        "default": {
          "dmPolicy": "open",
          "groupPolicy": "open",
          "allowFrom": ["*"],
          "groups": {
            "-1003873869691": {
              "requireMention": false,
              "enabled": true
            }
          }
        }
      },
      "actions": {
        "sendMessage": true  // ← 關鍵！原本是false
      }
    }
  }
}
```

### 核心教訓
**「單向性」元兇**: `actions.sendMessage: false`
- 這導致 Bot 能收到訊息但無法回覆
- 不是Privacy Mode問題，不是ignoreBots問題
- 是「自廢武功」的設定錯誤

## 🚫 Telegram Bot API 限制 (重要發現)

### 底層限制
- **Bot永遠無法看到其他Bot的訊息**
- 即使關閉Privacy Mode也無效
- 即使設為管理員也無效
- 這是Telegram伺服器端過濾，無法破解

### 解決方案
無法讓Bot互看，只能接受「平行回應」模式：
- 主人說話 → 所有Bot同時收到
- Bot A說話 → 只有主人看到，其他Bot看不到
- 這是特性不是Bug，保持現有架構即可
